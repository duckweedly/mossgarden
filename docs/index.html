输入一个种子颜色，Chroma 会基于色彩心理学和无障碍对比度，"生长"出一整套协调的配色方案。支持一键导出成 CSS 变量、Tailwind 配置或设计令牌。

最初是为了解决我自己每次配色都纠结半天的问题，后来发现很多人也有同样的烦恼，就开源了。目前有 1.2k star。
